# @tabdock/e2e

End-to-end tests and milestone demos. `src/harness.ts` starts the demo page in Chromium, MCP-B's local relay as a stdio MCP server, and an MCP client from the official SDK (M0). `src/tabdock-harness.ts` starts the Tabdock relay with throwaway dev tokens beside the demo page, opens the page with `?relay` and the `?e2e` test hook, connects MCP clients with a bearer header, and clicks inside the adapter's closed shadow root through the DevTools protocol (M1).

`test/*.test.ts` run in `pnpm test` without a browser: the relay, sim pages running the real adapter core, and MCP clients in one process, covering A1.1, A1.3 and A1.4 on the default sim profile (Chrome 156), with `runtimes.test.ts` running the pair, list and call path on every profile the sim page plays (MCP-B polyfill 5.1, Chrome 154, Chrome 156). The M2 acceptance tests sit beside them: `many-clients.test.ts` (A2.1, A2.3), `role-checks.test.ts` (A2.2, with `stand-in-relay.ts` playing a relay that skips its own check), `operator-controls.test.ts` (A2.4, A2.5, pause) and `call-lifecycle.test.ts` (idle expiry, argument checks, client cancellation on both protocol eras). `pnpm test:e2e` (from the root) runs the Playwright specs in `specs/`: the M0 baseline through MCP-B, the real adapter on the demo page against the Tabdock relay, and (`pair.spec.ts`, M3) the QR flow, where a phone-sized browser opens the widget's pairing URL, signs in at the relay tests' stand-in provider, joins, and sees the operator's click approve it. `src/public-harness.ts` runs that relay in public URL mode and plays the tunnel with Playwright routing: `https://relay.test` reaches the loopback relay with the public Host, so the phone has a real https origin with no certificate and no http allowance in the relay; since Playwright never routes a request a redirect produced, each redirect becomes a page that navigates on at once, and the browser still applies its own cookie and Origin rules to every hop. `pnpm demo:m0`, `pnpm demo:m1` and `pnpm demo:m2` narrate one session each; add `-- --headed` to watch or `-- --screenshot` to refresh `docs/tour/img/m0-board.png`, `m1-board.png` or `m2-board.png`. `pnpm --filter @tabdock/e2e baseline` re-measures the WebMCP runtime into `docs/notes/baseline.raw*.json`. `check:claude-code` (A0.2), `check:claude-code:m1` (A1.2) and `check:claude-code:m2` (Claude Code named in the page's roster and activity log) run the real Claude Code CLI; it must be installed and signed in, and each spends a few model calls.

Browsers: the harness and the Playwright global setup download Playwright's Chromium on first use. Set `CHROMIUM_EXECUTABLE` to use another Chrome, for example one with native WebMCP; the harness always passes `--enable-features=WebMCPTesting`.
