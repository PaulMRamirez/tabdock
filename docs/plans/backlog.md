# Carried-forward decisions

Decisions the owner made for later milestones, so each milestone plan picks them up.

## Priority order (proposed 9 October 2026)

On 9 October 2026 the owner asked for eight items to be drafted and prioritized for the target scenario in [map-classroom.md](map-classroom.md): a map and globe page used in classrooms. They are the rows dated 9 October below, each with a Proposed ADR, and they are proposals, not decisions, until each ADR is accepted; reorder here. An older row comes along only where it serves one of the eight, and is named beside it; every other row keeps its own timing.

1. A tool set for map and globe pages (ADR 0038): what the target page registers, so an integration starts from a shared shape.
2. Image results (ADR 0039): a client can see the map. Brings in: the MCP-B 6 test leg (`tests/mcpb6`), which runs the envelope; the demo's move to MCP-B 6 keeps its own trigger (5 October).
3. Page state clients can follow (ADR 0040): a room follows one tab. Brings in: measuring whether the adapter's Web Lock keeps a background tab from being frozen (2 October, for M3, still unmeasured).
4. Checking a page from CI (ADR 0041): every walkthrough checked on every change, in local mode; cheap, and it holds 1 to 3 to account.
5. Proposals from observers (ADR 0042): observers suggest, the operator accepts on the page. Brings in: SPEC section 12's open item on per-user fairness in the write queue.
6. Time-boxed sessions (ADR 0043): a lesson or a review starts and ends in one form, and the member list reloads without a restart. Brings in: the restart snapshot (3 October).
7. Larger read-only rooms (ADR 0044): an adult class can join one page. Brings in: the relay-wide ceiling on responses with bytes waiting (5 October), the no-account agent tokens on `/g/mcp` (3 October) and, for the reference deployment only, "Sign in with Google" (3 October).
8. A session record for the operator (ADR 0045): one record of a session, exported from the widget. The audit log route (3 October) stays as it is, for members' own calls.

Not brought in: the move to Node 24, whose date stands; the deny list of revoked provider sessions; deploys on merge, which still wait on the snapshot; the three residuals from the final A4.3 pass (4 October); ranking pages in the tool budget; measuring keys of digits alone; the Windows `headersHelper`; and the Connect bar's registrable domain.
