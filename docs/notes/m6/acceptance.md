# M6 acceptance audit

SPEC.md section 10's A6.1 to A6.26 read item by item against the tests on branch `m6-w3-d3` and its review fix `m6-w3-d3-fix`, which start from `8b8e4e7` on `m6` (Waves 1 and 2, W3-A, W3-B and W3-C merged). Each criterion is split into its clauses, and each clause names the test that holds it: a file and the case's title, cut short where it is long. A clause is **held** when an automated test in `pnpm test`, `pnpm test:e2e` or a CI job holds it; **recorded** when its figures come from a run made by hand and a test in `pnpm test` holds that run's record to the code as it stands, so a later change to what was measured fails until the run is made again; **by hand** when a spec in the repo holds it but needs a browser that neither `pnpm test:e2e` nor CI installs, so it was run by hand; **signed in** when its run needs Claude Code signed in, which this sandbox's `claude` is not, so it waits on the owner; and **manual** when only the owner's devices or accounts reach it, as `docs/checklists/M6.md` lists. A6.27 is that checklist, so it is not audited here; A6.28 is the section 9 review, and its one row, **reviewed**, points to the review's own record, `docs/notes/m6/section9-review.md`.

The audit adds four tests: Wave 3's own three, `tests/e2e/test/widget-names.test.ts`, `tests/e2e/test/m6-seams.test.ts` and `tests/e2e/specs/all-blocks.spec.ts`, for A6.26; and `tests/e2e/test/room-measure-record.test.ts` for A6.22, added after review, since the first version of this audit called A6.22 held though no test read the run's record. Four clauses are met a step aside from their letter, each said in its row. Native Chrome 155 and 156 (A6.3) is `image-results.spec.ts` run by hand with `CHROMIUM_EXECUTABLE` naming Chrome for Testing, because Playwright's bundled Chromium 141, the one `pnpm test:e2e` and CI use, has no native WebMCP; in `pnpm test` the sim page's `chrome-156` profile stands in, held by `fake-model-context.test.ts` to both browsers' measured baselines. "M5's seat tests" (A6.19) are the M5 cases that now say `observersPerPage: 0`. "35 joins" (A6.24) is a class of 40 joining by two invites. The CI jobs of A6.8 run on GitHub, their files held by `ci-check-files.test.ts`; of their scripts, `pnpm ci-check` was run here and `pack-install` was not.

Every automated test this audit names was run on 12 October. On `m6-w3-d3`, after the three were added, the 56 Vitest files passed with 838 cases (343 for A6.1 to A6.8 and 495 for A6.10 to A6.26); the eleven Chromium specs named here passed 40 cases, and the `mcpb6` project its 5; and `pnpm ci-check`, the CI job's own script, walked the canvas page and ended with the audit chain intact, 53 records and 49 call records. The `pack-install` job and the `ci-check` job itself run on GitHub only. `pnpm measure:room` was run by W3-C at `db9a115` on 11 October, not again here; `room-measure-record.test.ts`, added in the review fix on `m6-w3-d3-fix`, holds that run's record and passed its 6 cases. On 12 October `image-results.spec.ts` was also run by hand in Chrome for Testing 155.0.8059.39 and 156.0.8078.12, its 3 cases passing in each with the spec's runtime note reading native WebMCP, as `docs/notes/verified.md` records for 10 October.
