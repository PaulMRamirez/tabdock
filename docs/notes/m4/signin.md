## 4. "Hardened for production" for the plugin

Done in M3: issuer and audience pinned, RS256 only, `exp` and `sub` required, 5 s clock tolerance, 8 KiB header cap, 503 with `Retry-After` on a key outage, fixed error phrases, exact metadata issuer (`oauth.ts:79 to 83, 429 to 480`). Still to do:

1. **Token age.** Add `maxTokenAge` (jose then requires `iat` and refuses one in the future) and refuse `exp - iat` above a cap, about 2 h, so a provider setting cannot mint day-long tokens. Require `jti`. Leave `typ` unpinned (WorkOS sends none). jose 6.2.12 `lib/jwt_claims_set.js`. M.
2. **Replay.** Bearer tokens are replayable by design and Claude has no DPoP; a `jti` cache adds nothing for a token sent on every call. Instead: short lifetime, never logged, and a relay-side list of revoked `sid` values kept for the maximum token age, since WorkOS revocation does not reach issued JWTs. M.
3. **Key rotation.** Set jose's `cacheMaxAge` and `cooldownDuration` explicitly; after a rotation a new `kid` may be unknown for up to about 330 s (edge cache plus cooldown), each such request a 401 that sends Claude to refresh. Record it in the runbook; re-read provider metadata on a timer, not only at start. M.
4. **Invite claims.** Parse the two template claims with zod (email at most 320 characters, boolean), absent means "unverified account"; identity stays `sub`; add `email` to `REDACTED_FIELDS` (`log.ts`) so addresses reach the page UI, never logs. Turn the 403 for non-members (`oauth.ts:540 to 549`) into the invitee outcome behind the invites flag.
5. **Logging.** One fixed-reason line per refusal with the trusted client address, account kind and `client_id`, never token text; collapse repeated 401s per address so a flood cannot fill the persistent log.
6. **`/pair` and `/i` budget.** Today one relay-wide key, 60 a minute and 8 in flight (`pair.ts:62, 323, 532 to 537`). With the trusted proxy address, check a per-address share first (for example 10 a minute and 2 in flight, IPv6 grouped by /64), keeping the global budget as backstop; size it for carrier CGNAT, where many phones share one IPv4 address; `/i` draws on the same budget. Use the proxy's added address only when the TCP peer is the proxy.
