## Consequences for the build

M0 applied the scaffold fixes (Node 22.18, `allowBuilds`) and pinned every MCP-B reference to exactly 5.1.0. The owner accepted ADRs 0001 to 0006 on 2 October: the adapter detects the `executeTool` input form per page, parses string schemas and treats results as text (0001); consequential tools follow option C (0002); SPEC section 3 was refreshed from this file (0004); `pair_page` waits 50 s (0005); and a minimal OAuth plugin moves into M3 because request-header connectors are missing on the owner's account (0006).

M1 built the relay on the v2 SDK at 2.3.0 with the node adapter at 2.1.1, mounting `createMcpHandler` on `node:http`. `/mcp` checks `Host` but not `Origin`, since hosted Claude sends none; S1 and S2 apply to `/page`.
