# Map demo checklist

Written on 13 October 2026 for the map demo (ADR 0050, `docs/plans/map-demo.md`), the page at `/map/` on the Pages site that shows people what Tabdock can do. Everything the sandbox can check runs in its tests and headless Chromium; these are the steps only you can take, and the two choices only you can make. Each says what to send me; I record what you send in `docs/notes/verified.md` with its date. (C) marks a step that needs a computer. `<domain>` is your personal domain, as in M4's checklist.

## Publishing

1. [ ] **Publish the site.** After the pull request merges, dispatch Actions, Pages, Run workflow, branch `main`. A Pages deploy replaces the whole site, so this publishes the board, the tour and the guide beside the map; if the site has never been published, take step 7 of `docs/checklists/M5.md` first, since the domain's verification, the custom domain and Enforce HTTPS go in that order. Then open `https://demo.<domain>/map/` on your phone: it should show the globe, a Connect form and a line naming `https://demo.<domain>` as the origin your relay must list, and its links to the board, the tour and guide page 16 should open. Pages caches files for up to ten minutes, so a later fix can take that long to show. Send me anything that looks wrong at phone width.

## A real client

2. [ ] (C) **Claude Code from your computer.** In a clone, run `TABDOCK_ALLOWED_ORIGINS=https://demo.<domain> pnpm relay` and add the relay to Claude Code with the line it prints. Open `https://demo.<domain>/map/`, type `ws://127.0.0.1:8787/page` in the Connect form and click Connect. Chrome may ask whether the site may reach devices on your network, which headless Chromium in the sandbox never does; note what it asked. Ask Claude Code to pair with the code in the widget, click Allow as driver, and ask: "Take this page's tour and capture each stop." Send me what the browser asked, whether Claude Code described each capture, and anything it got wrong about a stop.
3. [ ] **Hosted Claude through the deployed relay.** Once the relay you deploy from `main` runs M6's code (`docs/checklists/M6.md`, On the reference deployment), its `TABDOCK_ALLOWED_ORIGINS` already names `https://demo.<domain>`, which the map shares with the board, so nothing changes on the relay. Open `https://demo.<domain>/map/?relay=wss://relay.<domain>/page`, click Connect on the bar, pair from Claude on the web or the Claude app on your phone, Allow as driver, and ask for the tour with a capture at each stop, then "Hide the graticule and list the lakes in view." Send me whether the model described the pictures and whether the widget left the map usable on the phone.
4. [ ] (C) **Film Claude itself: a shot list.** `pnpm record:map-demo` made the take in `apps/map-demo/media/` in the sandbox, where no Claude is signed in, so its client is a script on the MCP SDK and its pane says so; the page plays that take and the README shows its loop. A take of Claude needs your laptop, about two minutes of work, in local mode. Watch the sandbox's take first (`apps/map-demo/media/map-demo.mp4`, under a minute) for the shape to aim at.

   **Set up, off camera.** In a clone, run `pnpm relay` in one terminal and `pnpm dev:map-demo` in another, as `apps/map-demo/README.md` says. Paste the `claude mcp add-json` line the relay prints into a shell and check that `claude mcp list` shows `tabdock-local` as Connected; that line holds the path of a header helper, not the token, but on PowerShell the relay prints a `claude mcp add ... --header` line that does, so keep those terminals out of the shot either way. Claude Desktop reaches connectors from Anthropic's cloud and so cannot use a relay in local mode; to film it instead, run public URL mode (`pnpm dev:public`, guide page 07) and the rest of this list holds.

   **Lay out the screen.** Claude Code in a terminal on the left, about 40 percent of the width, its font at 16 points or more; Chrome on the right, open at the link `pnpm dev:map-demo` printed (`http://127.0.0.1:5175/?relay=ws://127.0.0.1:8787/page`), zoomed until the map fills its width. Close other tabs, hide the bookmarks bar and silence notifications.

   **Keep the pairing code off camera: pair first, fold the widget, then start recording.** Click Connect on the page's bar, ask Claude Code to pair with the Tabdock page using the code the widget shows, click Allow as driver, then click the Tabdock badge at the bottom right to fold the panel. Run `/clear` in Claude Code so the call that carried the code leaves the screen; the attachment belongs to the connection, so Claude finds the page again with `list_pages`, and if it says it is not attached, pair again, still off camera. A code works once and lives 120 s, but none belongs in the video. Scroll the page until the map sits at the top of the window.

   **Record** at 1280 by 720 or 1920 by 1080 and 30 fps, the screen or the two windows, with any screen recorder (QuickTime on a Mac, OBS anywhere). Type these prompts in order, letting each answer finish:
   1. "Take this page's tour, one stop at a time."
   2. "What are we looking at?"
   3. "Show me a picture of the view."
   4. "Take me to Lake Titicaca on the globe." (or any place you choose)

   Stop, then trim to 60 to 90 s, cutting waits but never a call or its answer, and watch it through once for the pairing code, a token or anything private in either window.

   **Add it.** For a player in the README, drag the MP4 into a comment box on GitHub (this pull request or an issue: GitHub's docs name issues, pull requests and comments, take videos up to 10 MB on a free plan and recommend H.264), then paste the link GitHub writes on a line of its own in the README, above the loop. To replace the take in `apps/map-demo/media/` instead, send me the file: I cut the MP4, WebM, poster and loop from it with the recorder's ffmpeg steps, to the same budgets (4,000,000 bytes for each video, 300,000 for the poster, 3,000,000 for the loop) and the same frame check, before it replaces this one. Send me the take or its link, and say whether the sandbox's take should stay on the page beside it.

## Choices

5. [ ] **Names on the map.** Lake names are Natural Earth's own but for one: the lake Natural Earth calls Lake Malawi is Lake Nyasa in Tanzania and Lago Niassa in Mozambique, so the page and its tools show "Lake Malawi (Lake Nyasa, Lago Niassa)", which takes no side, as ADR 0050 asks. Say whether to keep that, use Natural Earth's name alone, or leave that label out; I record the choice in ADR 0050's notes.
6. [ ] **The widget beside the map.** The widget's panel opens on its own, on pairing, an attach request or a prompt. On a screen 1,100 pixels or wider the page's column now leaves it a lane on the right, so the map stays whole beside it; on a phone it covers the map and the tour card until folded into its chip, and once a relay is chosen a line under the status says so. Say whether that reads well on your phone, or whether you would rather the panel stay folded until it needs you.
