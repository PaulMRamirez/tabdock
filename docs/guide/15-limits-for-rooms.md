# Limits for rooms, images and state

The fixed numbers behind images, page state, proposals, time-boxed sessions, the members file, larger rooms, agent tokens and the session record, each from the named constant. [Setup problems and limits](12-setup-and-limits.md) has the older ones, and the settings that change some of these are on [Settings for rooms, images and state](14-settings-for-rooms.md). The adapter holds the page to the same numbers the relay does, so a page never sends what the relay would refuse.

Waits share one more bound: a page holds at most as many as its people limit and watching seats together, and invitees on it that number less two. Each wait also holds its request's charge, so the byte budgets on [Relay settings](08-relay-settings.md) bound them too. The widget warns 5 minutes and 1 minute before a session ends, and agent tokens last 1, 4 or 8 hours, as the widget offers them.
