# @tabdock/map-demo

The map demo (ADR 0050): Earth as a flat map and a globe on a plain canvas, with no map library, running the map profile's tools from `@tabdock/sim-page/map`, published on the Pages site at `/map/`. It is private, never published to npm, and imports nothing from `tests/map-page`, which stays CI's fixture.

A visitor connects a relay of their own, pairs Claude or another MCP client in the adapter's widget, and asks it to move the map, take the six-stop tour, capture what it sees and follow the page's state. The page registers fourteen tools: every one of the profile's but its clock group, since this world has no clock, and `edit_stop` and `reset_edits`, under `MAP_PAGE_POLICY` with `capture_view` as its image tool, so only `reset_edits` asks the operator. `capture_view` draws the page's own map again on a canvas of its own, never the tab, and once linked the page publishes its view, stop and observation as page state on each change, never the same state twice.

It dials only a relay its visitor chose, by the board's rules: `?relay=` shows a Connect bar that takes only a person's own click once the button has held still, and without it the page offers a Connect form. The choice is remembered for the tab under `tabdock-map-demo:connect:`, apart from the board's. It reads no policy from its link, has no test hook in any build and never links inside a frame. To connect from the published page, your relay must list the site's origin in `TABDOCK_ALLOWED_ORIGINS`, and your browser may ask before a public page reaches a relay on your own machine.

## Run it

`pnpm dev:map-demo` serves the page on `http://127.0.0.1:5175/` (or `MAP_DEMO_PORT`, or `--port`), rebuilding as you edit, and prints a `?relay=` link for `pnpm relay`, whose development default admits any loopback origin. `pnpm --filter @tabdock/map-demo build` writes the static build into `dist/`: the page, its script minified and the script's source map, the page carrying the board's meta policy without `worker-src`. `scripts/server.ts` exports `buildMapDemo()`, which writes the same build into any directory, for the site to copy to `/map/`. ADR 0050's budget holds the build to 800,000 bytes of script (200,000 gzipped) and 16,000 of page, and the vendored data to 24,000.

## Files

`src/main.ts` wires the polyfill, the world, the tools, the canvas and the link; `src/earth.ts` holds the world, its tour and its outlines; `src/decode.ts` reads the vendored data; `src/projection.ts` holds the flat map's copies and the globe's limb; `src/draw.ts` draws a scene, `src/capture.ts` fits `capture_view`'s picture under the relay's cap, `src/gestures.ts` turns drags, the wheel and the buttons into one world write each, `src/publish.ts` sends the page state, `src/panel.ts` writes the view line, the tour panel and the call strip as text, `src/connect.ts` draws the Connect bar and form, using `@tabdock/demo/relay` and `@tabdock/demo/arming`, and `src/webmcp.ts` declares the slice of WebMCP the page uses. Unit tests sit beside the modules; `test/` holds those that read files or start the server.

## The data

The geography is Natural Earth's 1:110 million land and lakes at tag v5.1.2, which its terms place in the public domain, from [github.com/nvkelso/natural-earth-vector](https://github.com/nvkelso/natural-earth-vector). `src/data/natural-earth-110m.ts` is generated by `scripts/vendor-natural-earth.ts` and is never edited by hand: run `pnpm --filter @tabdock/map-demo vendor` (or the script with `--from <dir>` to read two files you already have) and it fetches `ne_110m_land.geojson` and `ne_110m_lakes.geojson` at the tag, stops unless each file's SHA-256 is the one it pins, rounds every position to 0.1 degree, winds rings as RFC 7946 asks and writes them in the compact form `src/decode.ts` reads. The same files give the same bytes, so a rerun shows no diff. No CI job runs it, and the page never fetches anything. The module carries the credit Natural Earth's terms suggest, "Made with Natural Earth.", which the page shows. Lake names are Natural Earth's own.
