# @tabdock/map-demo

The map demo (ADR 0050): Earth as a flat map and a globe on a plain canvas, with no map library, running the map profile's tools. It is private, never published to npm, and imports nothing from `tests/map-page`, which stays CI's fixture.

## The data

The geography is Natural Earth's 1:110 million land and lakes at tag v5.1.2, which its terms place in the public domain, from [github.com/nvkelso/natural-earth-vector](https://github.com/nvkelso/natural-earth-vector). `src/data/natural-earth-110m.ts` is generated by `scripts/vendor-natural-earth.ts` and is never edited by hand: run `pnpm --filter @tabdock/map-demo vendor` (or the script with `--from <dir>` to read two files you already have) and it fetches `ne_110m_land.geojson` and `ne_110m_lakes.geojson` at the tag, stops unless each file's SHA-256 is the one it pins, rounds every position to 0.1 degree, winds rings as RFC 7946 asks and writes them in the compact form `src/decode.ts` reads. The same files give the same bytes, so a rerun shows no diff. No CI job runs it, and the page never fetches anything. The module carries the credit Natural Earth's terms suggest, "Made with Natural Earth.", which the page shows.
